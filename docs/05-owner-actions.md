# Owner review and launch blockers

- [ ] Approve the concept design, wording and temporary wordmark, or provide official brand assets.
- [ ] Confirm exact business status and permissible company description.
- [ ] Confirm offered service scope.
- [ ] Confirm an official business email/contact intake channel; implement safe form handling if requested.
- [ ] Approve DWIIS product claims and any public imagery.
- [ ] Validate Eductrack spelling, current feature status and approved product copy.
- [ ] Classify each additional portfolio candidate by ownership, contribution, stage, evidence and visibility permission; do not publish private work by default.
- [ ] Provide approved founder biography and public social profile links.
- [ ] Replace or review draft privacy and terms pages with appropriate legal review.
- [ ] Confirm GitHub Pages eligibility for current private repository and required deployment environment.
- [ ] Approve canonical domain configuration and Cloudflare DNS edits.
- [ ] Test and approve generated site preview and end-to-end links before production.
- [ ] Supply a genuinely approved Open Graph image and favicon.
- [ ] Approve Search Console, analytics and cookies based on actual data practices.
- [ ] Explicitly approve production release.

## Maintenance

Weekly: check links and contact channel, review pending owner issues. Monthly: audit dependencies, security advisories, project statuses, Search Console and site performance. Quarterly: review privacy disclosures, site access, portfolio permissions, and recovery procedure.
